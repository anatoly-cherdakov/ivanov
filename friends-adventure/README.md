# Два друга — 8-битное приключение

Играть: https://anatoly-cherdakov.github.io/ivanov/friends-adventure/

**Версия 3**. Браузерная игра на основе неофициального FullScreenMario.

### Изменения
- Настоящее стартовое меню: часы игры не идут до нажатия «Играть».
- Выбор одного из двух персонажей по фотографии: чёрная ушанка или синяя шапка.
- Персонажи рисуются напрямую из подробного пиксельного атласа, использованного в первой версии, без предварительного преобразования в грубые 16×16 символы.
- Игра работает с внутренним разрешением 256×232 (масштаб ×2 до 512×464); по умолчанию отрисовка 30 к/с при физике 60 тиков/с, в меню можно выбрать 20 или 60 к/с.
- Библиотеки движка собраны локально в 6 файлов `engine-01.js` ... `engine-06.js` вместо 42 последовательных внешних запросов.
- Убрана большая панель конфигурации и редактор новых уровней.
- Сохранились 32 классических уровня (1-1 ... 8-4), враги, трубы, гриб роста. Герой начинает маленьким.
- Игра на одного, но можно выбрать, за кого из друзей играть; одновременно вдвоём играть нельзя.

### Запуск
Откройте `index.html` (или ссылку выше), выберите персонажа, уровень и нажмите **«Играть»**. Для запуска нужен интернет: звук и CSS ещё берутся с публичного CDN.

### Управление
- Стрелки ← / → или A/D — движение.
- Стрелка ↑, W, пробел — прыжок.
- Shift / Ctrl — бег.
- P — пауза.
- Кнопка «Сменить героя» ставит игру на паузу и открывает начальное меню.

### Исправлено (19 ноября 2026)
- **Звезда:** движок оставлен с исходным ограниченным временем неуязвимости и защитой от врагов; поверх персонализированных героев добавлены мигающее цветное свечение и пиксельные искры на время действия звезды.
- **Экран:** убраны нижняя надпись об адаптации, строка «32 классических уровня…», текст «Игра не начнётся…» и статус «Выбери персонажа. Таймер не запущен». Сведения об авторстве сохранены здесь и в лицензии.
- **Фотография:** над заголовком выбора героев размещено восьмибитное изображение совместной зимней фотографии. Данные изображения встроены в `photo-art.js`.
- **Огненные тельняшки:** вместо частичного перекрашивания курток применяется отдельный комплект полноценных спрайтов на все 5 поз для каждого героя из `fire-art.js`. Обычные изображения персонажей не менялись.
- **Piranha:** растение поражает только той частью, которая выступает выше края трубы и пересекается с персонажем. Когда оно полностью спрятано, урона нет. В процессе вылезания и возвращения оно опасно сразу при фактическом соприкосновении.
- **Огонь:** остаётся текстовая подсказка под игровым полем: `Shift / Ctrl`; кнопка под игровым полем не добавлена.

Фотография и спрайты упакованы в небольшие локальные JS-файлы с палитровым изображением; изображения восстанавливаются в браузере. Для этого используется стандартный `DecompressionStream` (поддерживается актуальными версиями Chrome).

### Управление на телефоне

Под игровым полем появляется сенсорный геймпад, стилизованный под Dendy:
- слева **A** — прыжок, **B** — бег и выстрел после получения огненного цветка;
- **A Turbo** — при удержании автоматически прыгает снова после каждого приземления, **B Turbo** — при удержании непрерывно ускоряет героя и многократно выпускает огненные шары после цветка;
- справа крестовина **← ↑ → ↓** — движение и приседание/вход в трубу.

Удерживание разных кнопок несколькими пальцами работает одновременно (например, **→ + A**). На ПК по-прежнему действует клавиатурное управление. Сенсорные кнопки видны только на мобильных/сенсорных экранах.
