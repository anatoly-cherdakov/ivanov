ОБНОВЛЕНИЕ РЕЗУЛЬТАТОВ ВЛАДИМИРА ИВАНОВА
Источник: https://run5k.run/users/ivanov

1. Откройте репозиторий GitHub, где размещён именно сайт Владимира.
2. В корне репозитория замените index.html и добавьте run5k-results.json
   и папку scripts с файлом fetch_run5k.py. Дополнительную папку из названия
   архива создавать не нужно.
3. В GitHub выберите Add file → Create new file.
   Имя нового файла: .github/workflows/refresh-run5k.yml
   Откройте в Блокноте файл refresh-run5k.yml из архива, скопируйте весь
   текст в редактор GitHub и нажмите Commit changes.
   GitHub создаст скрытую папку .github сам.
4. В Actions выберите «Обновление результатов Владимира Иванова» → Run workflow.
   Дождитесь зелёной галочки. Если GitHub Actions ещё не включён, разрешите
   запуск действий в этом репозитории. Если права записи запрещены настройками,
   включите Settings → Actions → General → Workflow permissions → Read and write permissions.
5. Откройте сайт и нажмите «Обновить результаты».

Имя репозитория заранее указывать не требуется: для адреса вида
https://имя.github.io/репозиторий/ страница определяет его автоматически.

Кнопка добавляет новые результаты из подготовленного файла, обновляет
верхние счётчики, статистику года, счётчик над картой, описание географии
и маркеры. Существующие оформления названий систем сохранены.
Повторное нажатие не создаёт дублей. Добавления сохраняются в браузере.

Фоновая задача получает данные с run5k.run по расписанию раз в 15 минут.
GitHub может задержать запуск. Кнопка читает данные прямо из репозитория,
поэтому для каждой новой записи не нужна повторная публикация GitHub Pages.
В другом браузере нажмите кнопку, чтобы получить те же результаты.

Если позже GitHub отключит расписание из-за отсутствия активности в
репозитории, включите его снова на вкладке Actions.
