# Два друга — пиксельное приключение

Небольшая браузерная игра в духе ретро-платформеров с двумя персонажами, созданными по фотографии.

**Играть:** [открыть страницу GitHub Pages](https://anatoly-cherdakov.github.io/ivanov/friends-adventure/) (если в репозитории активирован GitHub Pages).

## Как играть

- 1 игрок — выбрать героя в чёрном или синем, ходить на A/D или стрелках, прыгать на W/пробел/↑.
- 2 игрока — первый A/D/W, второй стрелками ←/→/↑, одновременно.
- P — пауза; R — начать сначала.

Собирайте монеты и бонусы, прыгайте на врагов сверху и доберитесь до флага. Есть поддержка сенсорного управления и полноэкранного режима.

`index.html` полностью автономный: весь JavaScript, стили и пиксельные персонажи находятся внутри единственного HTML-файла. Его можно скачать и открыть без установки чего-либо.

Независимая работа, не использующая ROM, музыку или графику Nintendo и не связанная с Nintendo.
