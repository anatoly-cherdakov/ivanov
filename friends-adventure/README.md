# Два друга — 8-битное приключение

Играть: https://anatoly-cherdakov.github.io/ivanov/friends-adventure/

**Версия 3**. Браузерная игра на основе неофициального FullScreenMario.

### Изменения
- Настоящее стартовое меню: часы игры не идут до нажатия «Играть».
- Выбор одного из двух персонажей по фотографии: чёрная ушанка или синяя шапка.
- Персонажи рисуются напрямую из подробного пиксельного атласа, использованного в первой версии, без предварительного преобразования в грубые 16×16 символы.
- Игра работает с внутренним разрешением 256×232 (масштаб ×2 до 512×464); по умолчанию отрисовка 30 к/с при физике 60 тиков/с, в меню можно выбрать 20 или 60 к/с.
- Библиотеки движка собраны локально в 6 файлов `engine-01.js` ... `engine-06.js` вместо 42 последовательных внешних запросов.
- Убрана большая панель конфигурации и редактор новых уровней.
- Сохранились 32 классических уровня (1-1 ... 8-4), враги, трубы, гриб роста. Герой начинает маленьким.
- Игра на одного, но можно выбрать, за кого из друзей играть; одновременно вдвоём играть нельзя.

### Запуск
Откройте `index.html` (или ссылку выше), выберите персонажа, уровень и нажмите **«Играть»**. Для запуска нужен интернет: звук и CSS ещё берутся с публичного CDN.

### Управление
- Стрелки ← / → или A/D — движение.
- Стрелка ↑, W, пробел — прыжок.
- Shift / Ctrl — бег.
- P — пауза.
- На игровом экране под полем есть кнопка **«🔥 БЕГ / ОГОНЬ»**. Удерживайте её для ускорения, коротко нажимайте для выстрела после получения огненного цветка. На клавиатуре те же функции выполняют **Shift** и **Ctrl**.
- Скрытие меню происходит до запуска игрового таймера; пока видно меню, ввод не направляется в игру.
- После перехода к внутреннему масштабу 256×232 исправлен вертикальный допуск столкновения Piranha (растения из труб): обычное касание должно причинять урон. Поведение звезды и временной неуязвимости определяется исходным движком.
- Спрайты персонажей и код их рисования не изменены.
- Кнопка «Сменить героя» ставит игру на паузу и открывает начальное меню.
