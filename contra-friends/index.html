Настоящая NES-игра через эмулятор. Не самодельная замена уровней.

Выбери файл своей копии Contra для NES. Файл остаётся в твоём браузере.
CONTRA · NESЗагрузи файл .nes — оригинальные уровни, музыка и механика запустятся без изменений.
Управление: стрелки — движение, Z — стрельба (B), X — прыжок (A), Enter — START, Shift — SELECT. Доступны геймпады и сенсорные кнопки. Чтобы выбрать двух игроков, используй SELECT на заставке Contra. Изображение и игровой процесс берутся из загруженного ROM, а не из старой игры game.js.
