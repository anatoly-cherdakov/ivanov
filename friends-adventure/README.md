# Два друга — классическое 8-битное приключение

Открыть игру: https://anatoly-cherdakov.github.io/ivanov/friends-adventure/

## Версия 2

Это персонализированный интерфейс к браузерному ремейку **FullScreenMario**. В отличие от первоначального прототипа здесь используются исходные 32 классических уровня (миры 1–8, по четыре), с подземельями, замками, трубами и секретными комнатами.

- Персонаж в чёрной шапке — герой из левой части фотографии.
- Персонаж в синей шапке — герой из правой части фотографии.
- С помощью двух кнопок в верхней части страницы можно выбрать, за кого играть. Игра воспроизводит одиночный режим платформера; **одновременного кооператива здесь нет**.
- В начале уровня герой маленький. Гриб делает его большим; вместе с движком сохранены классические монеты, вопросительные блоки, враги и прохождение по флагштоку.
- Игры и новые уровни от себя не добавлялись. На панели **Maps** доступны уровни 1-1 ... 8-4.
- Стандартное управление: ← → (или A/D) — движение, ↑ (или W, пробел) — прыжок, Shift/Ctrl — бег, P — пауза.
- Кнопка «↻ 1-1» возвращает к началу первого уровня.

## Техническая информация

Основной файл — `index.html`, без отдельной настройки GitHub Pages. При запуске HTML загружает код и ресурсы браузерного движка из публичного репозитория FullScreenMario через jsDelivr; **для игры нужен интернет**. Это не собственная копия ROM-файла NES.
